# Design: HTML-презентация «Анастасия»

Дата: 2026-10-23  
Контекст: институтский доклад (спокойный академический тон)

## Цель

Одна самодостаточная HTML-презентация о мультфильме «Анастасия»: описание главных героев и альтернативный финал (Аня и Дмитрий выбирают друг друга). Текст и картинки на слайдах разделены: слева текст, справа изображение.

## Подход

Один файл `anastasia-presentation/index.html`. Получатель открывает его на ноуте с интернетом — картинки и шрифты подгружаются по URL. Без Reveal.js, без локальной папки `images/`, без сервера.

## Структура слайдов (12)

| № | Слайд | Макет |
|---|--------|--------|
| 1 | Титул: название, тема, поля ФИО/группа | центрированный текст |
| 2 | О мультфильме: год, студия, краткий сюжет (2–3 предложения) | текст слева / картинка справа (постер или общий кадр) |
| 3 | Анастасия | текст \| картинка |
| 4 | Дмитрий | текст \| картинка |
| 5 | Владик | текст \| картинка |
| 6 | Распутин | текст \| картинка |
| 7 | Императрица Мария | текст \| картинка |
| 8 | Софи | текст \| картинка |
| 9 | Барток | текст \| картинка |
| 10 | Наш финал | текст \| опциональная картинка |
| 11 | Почему такой финал (2–3 аргумента) | текст (можно без картинки или с одной) |
| 12 | Заключение / спасибо | центрированный текст |

### Содержание слайда героя

- Кто это (роль в сюжете)
- 2–3 черты характера / функция в истории
- Без фанатского сленга; формулировки для устной защиты

### Альтернативный финал

Аня и Дмитрий остаются вместе: она выбирает любовь и новую жизнь, а не только возвращение к трону. На слайде 11 — аргументы: ценность личного выбора, смысл пройденного пути, гармония с темой «найти себя».

## Визуал и UX

- Палитра: тёмно-синий фон, золотой акцент, светлый текст (отсылка к мультфильму, без «кричащего» UI)
- Крупная типографика, читаемая с проектора
- Герои и обзор: колонки ~45% текст / ~55% картинка
- Навигация: ← →, пробел, клик; индикатор номера слайда
- Язык: русский

## Изображения

Картинки по HTTPS-ссылкам (Wikimedia / свободные источники). Интернет у получателя обязателен. Один отправляемый файл — `index.html`.

## Доставка

Отправить один `index.html`. Открытие двойным щелчком (`file://`) должно работать при наличии сети.

## Технические требования

- Работает при открытии `index.html` локально (file://) без сборки и сервера
- CSS и JS внутри одного HTML
- Интернет обязателен: Google Fonts + изображения по HTTPS
- Адаптив: на узком экране колонки складываются (текст сверху, картинка снизу)

## Вне скоупа

- Генерация или скачивание картинок
- Reveal.js / PowerPoint / PDF-экспорт
- Аудио, видео, сложные анимации
- Интеграция в Next.js loveApp

## Критерии готовности

1. 12 слайдов листаются с клавиатуры и мыши
2. Все герои из полного состава описаны
3. Финал и обоснование присутствуют
4. Без картинок презентация остаётся читаемой (плейсхолдеры)
5. Тон подходит для институтской защиты
